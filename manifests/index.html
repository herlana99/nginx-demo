Kenapa Nginx?

Arsitektur event-driven yang ringan dan efisien, dipakai oleh jutaan situs terbesar di dunia.

Performa Tinggi

Menangani ribuan koneksi bersamaan dengan konsumsi memori yang sangat kecil berkat model asinkron non-blocking.

Keamanan Solid

Dukungan TLS/SSL modern, HTTP/2, HTTP/3, rate limiting, serta proteksi terhadap serangan DDoS dasar.

Load Balancing

Distribusi trafik ke banyak server backend dengan metode round-robin, least-connected, hingga IP hash.

Reverse Proxy

Menjadi gerbang tunggal di depan aplikasi Node.js, Python, PHP, atau container — lengkap dengan caching.

Caching & Kompresi

Cache konten statis dan dinamis, plus kompresi Gzip/Brotli otomatis untuk mempercepat waktu muat.

Konfigurasi Fleksibel

Sintaks deklaratif yang mudah dibaca, mendukung modul dinamis, dan bisa di-reload tanpa downtime.

Mulai dari satu file konfigurasi

Semua kekuatan Nginx dikendalikan lewat file teks sederhana. Berikut contoh konfigurasi virtual host yang siap pakai.

  • Serving file statis — HTML, CSS, gambar, dan aset lain langsung dari disk.
  • Reverse proxy — teruskan /api/ ke aplikasi backend di port lokal.
  • Header asli klien — kirim IP dan host yang benar ke aplikasi.
/etc/nginx/sites-available/default 
server {
    listen       80;
    server_name  contoh.com www.contoh.com;

    root   /var/www/html;
    index  index.html index.htm;

    # Sajikan file statis
    location / {
        try_files $uri $uri/ =404;
    }

    # Proxy ke aplikasi backend
    location /api/ {
        proxy_pass         http://127.0.0.1:3000/;
        proxy_set_header   Host              $host;
        proxy_set_header   X-Real-IP         $remote_addr;
        proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
    }

    # Kompresi
    gzip on;
}
